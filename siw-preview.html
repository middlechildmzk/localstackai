SourcingOS Backend Preview

Sourcing Intelligence Workspace

This is the phone-openable preview shell for the backend branch. The real database/API stack uses Docker, FastAPI, Postgres, Redis, OpenSearch, and Celery. Vercel can show this preview page, but it cannot run the full local database stack by itself.

Implemented Core

FastAPI routes, Docker Compose, Postgres schema, OpenSearch indexer, Celery worker, Redis queue, source contract, batch ingestion, seed records, and compliance erasure flow.

Research Layer

API v1 scaffold for identities, sources, explainable role scores, provenance, feedback, research summary, observability, and skill graph queries.

Safety Boundary

No restricted-platform scraping. No auto-outreach. No protected-trait inference. Public or user-approved records only. Erasure workflow included.

What to run locally later

When you are back on a computer, the real database viewer is available after running:

docker compose up -d postgres redis opensearch ollama

docker compose up -d api worker

python scripts/seed_public_records.py

Then open http://localhost:8000/db/view.
